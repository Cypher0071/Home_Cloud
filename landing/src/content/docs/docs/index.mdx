Home Cloud is a web dashboard for one Linux machine. It gives you a host terminal, a file manager, Docker and Compose management and live system stats in the browser. The installer can also put it on your own domain over HTTPS through a Cloudflare Tunnel, with no port forwarding.

It is open source under Apache-2.0, built for a single owner, and runs as a regular systemd service on the Linux you already have.
